# Responsibilities and collaborators

TypeScript module paths identify ownership; this repository does not use C# namespaces. Proposed download files are provisional and should remain functions/types unless implementation demonstrates a need for a class.

| Owner                                                      | Responsibility / invariant                                                                                                                                                                                                                           | Collaborators / workflows                                  |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `src/client/vanta-client.ts:VantaApiClient`                | Reuse authentication, deadlines, cancellation, and safe retries. Introduce an explicit binary response path; never decode a file as text. Preserve JSON/error behavior. Define body-consumption lifetime so cancellation covers transfer completion. | request context, download helper, endpoint dispatch; W1–W4 |
| `scripts/generate-tools.ts` and generated descriptors      | Carry response/media classification or a minimal reviewed operation policy when upstream metadata is insufficient. Regeneration must preserve transfer behavior and tool identities.                                                                 | pinned specs, parity verifier, operation schema; W1, W4    |
| Proposed `src/downloads/*` helper and receipt types        | Stream exact response-body bytes to an exclusive temporary file; count and hash saved bytes; enforce limits; atomically publish without default overwrite; remove incomplete artifacts. Separate original identity from transfer success.            | client, filesystem, envelope; W1–W3, W7                    |
| `src/tools/operation-schema.ts`                            | Validate download destination/options; keep runtime-only fields out of upstream body/query. Retain existing input and mutation gates.                                                                                                                | generated descriptors, endpoint dispatch; W1, W4           |
| `src/tools/endpoint-tools.ts:invokeGeneratedOperation`     | Route media responses to downloader; return compact receipt; preserve normal envelopes and existing implementation-write readback. Diagnose known policy/evidence mismatch without claiming universal ID detection.                                  | client, downloader, envelope, schemas; W1–W4, W9           |
| `src/tools/compat-tools.ts` and `src/registry.ts`          | Ensure compatibility aliases use the same corrected path and registered-tool checks exercise it. Do not fix unused legacy handlers in isolation.                                                                                                     | endpoint dispatch, capabilities; W1, W3, W9                |
| `src/workflows/index.ts` and `src/workflows/pagination.ts` | Extend selected-vendor and issue review with independent bounded inventories. Plan actions before writes, preserve partial outcomes and resume cursors. Keep risk/personnel/framework orchestration small.                                           | generated operations, envelopes; W5–W8                     |
| `src/envelope.ts`, capabilities and help modules           | Describe successful retrieval, hash comparison, limitations, installed version, and executable fallback without embedding file bytes or signed URL secrets in text/logs.                                                                             | all tools; W1–W9                                           |
| Existing `src/uploads/*`                                   | Preserve Markdown source versus converted upload identity; expose hashes/provenance only as needed for download comparison. No upload redesign is required.                                                                                          | downloader receipts, workflows; W2, W7                     |

Design review checks: avoid a parallel HTTP stack, a generic artifact framework, automatic browser automation, and new workflow classes duplicating existing services. Resolve binary response streaming ownership before implementation so a returned stream cannot outlive its request deadline accidentally.
