# Edge cases and acceptance implications

Epic 248793. These requirements feed W1–W9 and the phase gates before implementation.

| Condition                                                               | Required behavior / test                                                                                                                                                                                                             |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| PDF/XLSX/image contains invalid UTF-8, NUL, or all byte values          | Hash and save raw bytes; no `.text()`, string reconstruction, or model-mediated byte recovery. Include a non-UTF-8 fixture through registered MCP dispatch.                                                                          |
| Text/CSV/JSON is itself an attachment                                   | Explicit file mode preserves original bytes, BOM, newlines, and encoding. Optional text preview is separate and labeled. Ordinary JSON APIs keep current semantics.                                                                  |
| MIME absent, incorrect, or HTML login response returned with 200        | Preserve observed metadata; validate expected file signature where applicable; report suspicious/nonmatching content instead of treating a login page as evidence. Do not invent a correct MIME from the filename.                   |
| PNG filename but JPEG response                                          | Save actual bytes; receipt reports filename/MIME/signature discrepancy and source-hash mismatch/unknown. Never re-encode merely to match the extension.                                                                              |
| Markdown converted on upload                                            | Compare download with converted artifact hash when available, while retaining original Markdown provenance separately.                                                                                                               |
| No expected hash, weak ETag, or matching Content-Length only            | Download can complete; original-file identity remains unknown. ETag/length are not SHA-256 evidence.                                                                                                                                 |
| Expected hash differs                                                   | Report completed transfer plus explicit identity mismatch; do not report identity verification or silently discard/replace the evidence. Decide retention policy in phase 0.                                                         |
| Compressed transfer                                                     | Hash the saved response entity bytes. Record decoded byte count; do not compare compressed Content-Length blindly with saved length or claim wire-byte identity.                                                                     |
| Empty body, truncated stream, timeout, cancellation, size overflow      | Distinguish documented empty file from missing/failed content. Never publish partial file as success; clean temporary file. Test absent/incorrect length and midstream failure.                                                      |
| Large/chunked file and concurrent same-destination writes               | Stream with configured limit and backpressure; avoid base64/token/memory inflation. Exclusive staging plus no-overwrite default prevents collisions. Bound duration and bytes.                                                       |
| Untrusted Content-Disposition filename or explicit local path           | Resolve destination in configured download root; reject traversal/device/reserved names as applicable; account for symlink/reparse-point escape; never use raw header path. Tenant outputs must not collide.                         |
| 401/403/404/429 and malformed JSON error body                           | Preserve HTTP/error behavior; do not save errors as artifacts. Retry safe reads within deadlines; retry transfer from a fresh temporary file without appending duplicate bytes.                                                      |
| Redirect or signed external URL                                         | Establish actual API behavior first. Allow only reviewed HTTPS targets; never forward Vanta bearer token cross-origin; bound redirects and redact signed query strings. Block untrusted targets rather than fetching arbitrary URLs. |
| Policy version artifact ID returns document 404                         | Keep object kinds and version identity; no fallback upload, remap, or renamed ID. Return an explicit unsupported/unresolved result and handoff instructions.                                                                         |
| Authenticated preview works; browser download fails                     | Record preview-only result, exact version inspected, and unresolved local retrieval. User-supplied approved PDF is a distinct provenance path.                                                                                       |
| Local destination returned by remotely hosted MCP                       | State destination is on MCP host; do not pretend it is on caller's machine. Validate a host-supported resource/download handoff or report delivery unavailable.                                                                      |
| API refresh changes required fields/enums/nullability                   | Classify migration impact; test changed requests and response-dependent workflows. New response fields alone should not break tolerant parsing.                                                                                      |
| Bulk mapping/alert updates reject one item or are eventually consistent | Preserve per-item results, bound readback, and expose unverified outcomes. Do not replay ambiguous writes.                                                                                                                           |
| Audit/Connector feature or scope unavailable                            | Record permissions gap, not code success or empty inventory. Keep local contract tests and live acceptance distinct.                                                                                                                 |
| Framework/group destructive action or replacement set                   | Present affected object, scope, and complete desired set; preserve omission versus empty; verify contract semantics and readback.                                                                                                    |

## Open questions

Phase 0 must resolve download limits, allowed root/overwrite behavior, installed MCP host topology, hash-mismatch retention, and client resource delivery support. Phase 2 must establish whether a documented policy artifact route exists. Export URLs and newly introduced asynchronous jobs require endpoint-specific review before reuse of the file transfer path.
